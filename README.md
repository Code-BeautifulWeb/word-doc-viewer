Word Document Viewer

Word Document Viewer is a lightweight, view-only plugin for Obsidian Desktop on macOS, Windows, and Linux.

It allows you to open and view Microsoft Word (.docx) documents directly within your Obsidian workspace—without relying on external desktop applications, complex editing tools, or unnecessary interface clutter.

Key Features

* 📄 View .docx files directly in Obsidian
* 🎯 High-fidelity document rendering for a more accurate representation of Word documents
* ↔️ Responsive, full-width layout that adapts naturally to your Obsidian workspace
* 📃 Authentic paper-style document presentation for a familiar reading experience
* 🔒 View-only by design, with no editing tools or unnecessary complexity
* 🖥️ Built specifically for Obsidian Desktop on macOS, Windows, and Linux

Whether you want to quickly review a document, reference project files, or keep Word documents accessible alongside your notes, Word Document Viewer provides a simple and focused viewing experience directly inside Obsidian.
